# 쓰고 있는 기능 정리

Claude Code 확장 수단은 5가지뿐입니다. 지금 상태를 층별로 적습니다.

| 층 | 하는 일 | 강제력 | 우리 상태 |
|---|---|---|---|
| CLAUDE.md | 항상 읽히는 지시문 | 없음 | 루트 `CLAUDE.md` (전역·하위는 없음) |
| Skill | 부를 때만 읽히는 절차서 | 없음 | `meeting-minutes` 1개 |
| 서브에이전트 | 별도 컨텍스트 일꾼 | 없음 | 미사용 |
| **MCP** | **바깥 세계와의 배선** | 없음 | 5개 연결 |
| 훅 | 도구 호출 전후 내 코드 | **있음** | 프로젝트 전용 없음 |

**MCP 만 «없던 능력» 을 추가합니다.** Skill 은 문서라서 자체 능력이 없고, 도구를 언제 어떤 순서로 쓸지만 지시합니다.

---

## 1. MCP (외부 배선)

```
claude mcp list      # 상태 확인
claude mcp add <이름> -- <명령>
```

| 서버 | 상태 | 용도 |
|---|---|---|
| Notion | ✔ | 회의록 페이지 생성. `ada00004@gmail.com` 개인 워크스페이스 |
| Google Drive | ✔ | 검색·읽기 중심 (업로드는 `SEND=api` 가 담당) |
| Gmail / Calendar | ✔ | 미사용. 회의 전 브리핑 등에 쓸 예정 |
| **Playwright** | ✔ | 브라우저 조작 (클릭·입력·스크린샷) |
| Slack / Figma / Atlassian | ! 미인증 | claude.ai → 설정 → 커넥터에서 인증 |

### Playwright 주의

- **Google 로그인은 못 합니다.** 자동화 브라우저를 Google 이 차단합니다
- 로그인이 필요하면 기존 프로필에 붙입니다:
  ```powershell
  & "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
  claude mcp add playwright-cdp -- npx -y @playwright/mcp@latest --cdp-endpoint http://localhost:9222
  ```
- 쓸 곳: HTML 뷰어 확인 · **병원 앱 화면 계측**(덱의 «실측 먼저» 규칙) · 사내 도구 폼 입력

## 2. Skill

```
office_automation/meeting_minutes/.claude/skills/meeting-minutes/SKILL.md
```

해당 폴더 아래에서 작업할 때만 로드됩니다. 회의록 절차(입력 고정·quote 강제·미확인/미조사 구분)를 담고 있습니다.

`/skills` 로 목록 확인. 다른 프로젝트(LLM퀀트)에도 스킬이 있지만 이 리포와 무관합니다.

## 3. 인증·자격증명 위치

| 무엇 | 어디 | 커밋됨? |
|---|---|---|
| Claude Code 로그인 | 계정 (claude.ai) | — |
| MCP 커넥터 OAuth | claude.ai 계정 | — |
| Playwright 등록 | `~/.claude.json` (AI_hub 프로젝트 스코프) | X |
| Drive OAuth 클라이언트 | `meeting_minutes/credentials.json` | X (gitignore) |
| Drive 사용자 토큰 | `meeting_minutes/token.json` | X (gitignore) |
| gcloud 로그인 | `%APPDATA%\gcloud` | — |
| 파이프라인 설정 | `meeting_minutes/.env` | X (gitignore) |

**API 키는 안 씁니다.** 추출은 `claude -p`(CLI), 드라이브는 OAuth.

## 4. Google Cloud 상태

```
프로젝트   meeting-minutes-mm1-506707     ← credentials.json 이 속한 곳. Drive API 켜짐
           meeting-minutes-mm1             ← 빈 프로젝트. 지워도 됨
계정       ada00004@gmail.com  (테스트 사용자로 등록됨)
스코프     drive.file  = 이 앱이 만든 파일만 접근
비용       무료 (Drive API 는 유료 등급 없음)
```

> 프로젝트가 두 개로 갈려서 «Drive API has not been used in project ...» 오류가 났던 적이 있습니다.
> `gcloud projects create` 가 ID 에 접미사를 붙이는 것이 원인이었습니다.

## 5. 아직 안 쓰는 것

| | 언제 쓸까 |
|---|---|
| **훅** | 「저번에도 이랬는데」 한 일이 생기면. 미리 만들지 않음 |
| 서브에이전트 | 조사·검증을 떼어 보낼 일이 생기면 |
| ECC 플러그인 | 마켓플레이스만 등록됨. 규칙·에이전트 한 벌이 필요해지면 |
| 전역 CLAUDE.md | 개인 작업 방식이 프로젝트를 넘어 반복되면 |

훅 후보는 실제로 데인 것들입니다 — 노트북 출력에 회의 내용 남은 채 커밋, `.env` 하드코딩 재발, 스키마 변경 시 템플릿 전파 누락.

### ⚠ 확인 필요: 전역 훅 11개가 빈 명령입니다

`~/.claude/settings.json` 에 11개 이벤트(`SessionStart`·`PreToolUse`·`Stop` 등)가 등록돼 있는데
명령이 **`C:\Windows\System32\conhost.exe` 하나뿐, 인자가 없습니다.**

```
SessionStart / UserPromptSubmit / Stop / StopFailure / SubagentStart /
SubagentStop / TeammateIdle / PreToolUse / PostToolUse /
PostToolUseFailure / PermissionRequest   -> 전부 conhost.exe
```

`conhost.exe` 는 Windows 콘솔 호스트라 인자 없이 실행하면 **아무 일도 하지 않습니다.**
의도한 설정이 아니면 지워도 됩니다 (`/config` 또는 settings.json 편집).
알림·소리용으로 넣으신 것이면 `conhost.exe` 뒤에 실제 명령이 붙어야 동작합니다.
